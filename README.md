# 💤 Sleep Health Analysis — EDA

## 📌 About
A Data Science project exploring patterns between **Insomnia and Sleep Apnea** using Python and Exploratory Data Analysis (EDA).

## 🎯 Objectives
- Analyze sleep duration and sleep quality
- Study stress and sleep quality
- Explore BMI, age, gender, and occupation patterns
- Compare blood pressure, heart rate, physical activity, and daily steps

## 🧹 Data Preparation
- 374 initial records
- 242 duplicate records removed
- Categories standardized
- Blood pressure converted into numerical values
- Final comparison: **59 records**
  - 29 Insomnia
  - 30 Sleep Apnea

## 📊 Key Insights
- Insomnia showed slightly higher average stress.
- Sleep Apnea showed higher average blood pressure and heart rate.
- Higher stress generally showed lower sleep quality.
- Sleep Apnea had higher average physical activity and daily steps in this dataset.
- Age, BMI, gender, and occupation showed different disorder patterns.

## 🛠️ Tools Used
Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook

## 📁 Project Files
- `Sleep_Health_Analysis.ipynb` — Python code and EDA
- `Sleep_Health_Analysis.pdf` — Complete project presentation

## ⚠️ Limitation
The analysis is based on a small, cross-sectional dataset and identifies **patterns, not causes**.
